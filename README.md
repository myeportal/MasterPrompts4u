# MasterPrompts4u Funnel Build

Modern static JVZoo-style affiliate funnel build for `masterprompts4u.com`.

Included pages:
- `index.html` — main landing / VSL page
- `checkout.html` — checkout handoff page
- `upsell.html` — OTO page
- `downsell.html` — lighter fallback offer
- `offer-wall.html` — thank-you / offer wall page

Notes:
- built as a stronger, more funnel-aware interpretation than PromptBase-style browsing alone
- uses local placeholder SVG visuals for easy brand swaps later
- replace config placeholders with real checkout / JVZoo destinations later
